# ArcPulse 

> Real-time RPC latency observability, live gas fee canary, and developer connection toolkit for Circle's Arc Layer 1.

- **Live Hosted Application:** https://tinyurl.com/arc-pulse
- **Target Network:** Arc Mainnet (Chain ID 5042)
- **Native Gas Token:** USDC (18 decimals)
- **Smart Contract Address:** `0x6295b9c03fa0e982d619932adbebf09121d5a574`
- **Block Explorer:** https://explorer.arc.io

### About the Project
ArcPulse is a developer health canary and observability terminal engineered specifically for Arc Mainnet. It tests real-time JSON-RPC latency across Circle, QuickNode, Blockdaemon, and dRPC, tracks native USDC gas mechanics, and provides connection boilerplates for Viem, Ethers, Hardhat, and Foundry.
